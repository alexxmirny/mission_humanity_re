    Description

    The ammunition used in needle guns was quite efficient against human infantry, but it didn't work so well in combat with their vehicles. The gun and machine-gun improvement project aims to create a new ammo ejection mechanism. Thanks to a higher muzzle velocity the ammunition will better penetrate armoured enemy vehicles. Installing the active core in missiles and bombs will increase the firepower of tanks and bombers. This project is extremely important, because available technical data on enemy tanks shows their advantage in this respect.
