# pl_extra.txt -- the Polish strings WE wrote for the pl language pack (RL18). Not retail data.
#
# src/formats/langpack_pl.py builds lang\pl from the Extermination install (retail text, CP1250) and
# fills what Extermination does not have, or has in a shape Mission: Humanity cannot use, from this
# file. Everything below is our own wording and is committed; everything retail is not.
#
# Format: `[section]` headers, then `key = value` lines. A value wrapped in "double quotes" keeps
# its leading/trailing spaces (the quotes are dropped). `\n` stays a literal backslash-n: it is the
# game's line-break escape, not a newline in this file. UTF-8, `#` comments.
#
# [initlang]  TEXT entries of Mission: Humanity's initlang that Extermination lacks (21 keys: the
#             alien "_a" variants, the unit suffixes, five newer messages) plus the two whose
#             Extermination text lacks the %s the MH code hands them (K_MENU_MsgMove,
#             K_MENU_MovingControl), reworded so the printf shape equals MH English's exactly.
#             The alien "_a" buildings use the pack's own building names (kopalnie, elektrownie,
#             kolonii: Extermination names the alien buildings Kopalnia / Elektrownia / Kolonia), the
#             alien colonists are "trutnie" (drones), as in MH English.
# [info]      info\INFO.TXT blocks MH has and Extermination does not (1 block: obcy_pr\OU_99.INF, a
#             placeholder in English too: "Do not translate. Additional description, not use in.").
