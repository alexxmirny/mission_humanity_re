# S7 acceptance: the row must read EXACTLY "occ/cap" (single slash, no '+'), where occ = occupied slots
# incl AI and cap = capacity after closed slots. A host with 1 human on an N-slot map (no AI, no closed
# slots) reads "1/N". Compare against the pre-S7 render "N-1+1/N" (e.g. "7+1/8").
#
# HOST PREREQUISITE: a host sitting in its lobby, LISTENING on 6501 (run mp_menu_walk.txt on the host).
# The runner rewrites this client's setup.dat "Server address" to the host IP (--connect-ip).
