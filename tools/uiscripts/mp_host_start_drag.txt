# RES12: mp_host_start.txt, then the HOST (one peer only) drag-selects at 1920x1056 while the lockstep match runs.
#
# The determinism claim is that the drag-select box's outline, its corner placement and the camera scroll that moves its anchor
# are view state: the selection and the orders a drag produces come from the WORLD corners only. This script makes it a
# measurement -- `test_ui.py --determinism --det-drag` runs it on the host and the stock mp_client_start.txt on the client, and
# mp_analyze must still report ALL PAIRS IDENTICAL after boxes in view, across the seam, with the anchor scrolled more than K px
# off the left (the res_drag_box scenario) and an order for the selection.
#
# Pair with mp_client_start.txt. The host's ini (tools/uiscripts/ini/drag_det_host.ini) lists the sizes the in-game size change
# walks along: [2] 1024x768 -> four clicks -> [6] 1920x1056.
