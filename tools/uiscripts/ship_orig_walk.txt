# ship_orig_walk -- the ORIGINAL-configuration twin of ship_walk: the same process shape (mh.dll without libmh.dll) with
# [config] mode=original (ini/rollback_original.ini), so every promoted body runs as the retail one. It walks the four
# segments of ship_walk that had an `_orig` row: shift_rearm_build, res_drag_box, res_drag_wide, wheel_hud_lists. Captures are
# named <old _orig row>__<name> and diff against the SAME frames ship_walk's segments do (copied into baselines/ship_orig_walk/):
# the claim of an _orig row is that the original code draws what the shipped code draws. The segment order, the in-game size
# reset between the drag segments and the 12-entry Load list (`2-almost*11,ayy30`, the HUD segment picks the last row) are
# ship_walk's; see its header.
