# mods:LANG3 -- mp_host_chat_glyphs.txt (mp:F3b) on the RU LANGUAGE PACK: the EN exe with `[lang]
# pack=ru` (built by `python src/formats/langpack.py build`), whose mh_ex carries the RU fonts merged
# with the EN Latin accents (fnt.merge_onto) and the RU text table. Same walk, same Cyrillic line, same
# CP1251 pin; what differs is every dialog label, which is now Russian -- so the waits/clicks name the
# pack's own initlang TEXT (K_MENU_PlayersTitle "Имя игрока", K_MENU_CreateGame "Создать игру",
# K_MENU_GamesString "Имя игры", K_MENU_MapsAvailable "Доступные карты", K_MENU_Players "Игроки в
# сети", K_MENU_Start "Начать"; K_MENU_Ok stays "Ok"). A non-ASCII label is matched as UTF-16 by
# ui_drive.cpp's wide_label_matches (2026-09-29); before that, no Cyrillic label could match at all.
#
# Its own script (not mp_host_chat_glyphs.txt with a different ini) because the labels differ and a
# shared script would share -- and clobber -- one baseline directory across two lane sources.
#
