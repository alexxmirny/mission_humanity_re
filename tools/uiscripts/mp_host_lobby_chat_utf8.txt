# mp:MP-LANG lobby follow-up -- TWO-PEER LOBBY chat in UTF-8, both directions, across two codepages.
#
# The claim: the lobby's own chat field (a menu edit field, NOT the in-game line) is typed, edited,
# echoed, sent and received as UTF-8, independent of either peer's codepage. This peer (the host) runs
# the process codepage (CP1252 on the rig) -- which has NO byte for any Cyrillic letter, so before the
# follow-up the six keystrokes below typed NOTHING useful here (and in a name field, Latin letters).
# The client pins CP1250.
#
# The line also exercises every edit the field does itself on a multi-byte character: `ы` + backspace
# (a 2-byte erase), a left arrow over `ź` (a 2-byte step), `!` typed mid-line by the ORIGINAL (ASCII)
# at a cursor our edits placed, and End (the original's own re-measure over the decoded line). The
# field buffer is asserted byte for byte before Enter; the local echo and the client's reply are
# asserted as code points in the lobby log (`wlobby`), and both frames are captured.
#
# Lanes: both peers from MH_FONT_MERGE_DIR (the merged install -- glyphs for Cyrillic AND Polish).
# Runner: test_ui.py lobby_chat_utf8

# _G_LLM_NET_ROSTER_LIVE[local slot].name -- empty (": Привет") until mh.dll mirrored the lobby slot
# names into the roster (mp:MP-ECHO-NAME).
