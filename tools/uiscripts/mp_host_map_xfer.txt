#   client 1  pretend=none    map_absent        the map is missing -- Start is HELD, the map crosses channel C
#   client 2  pretend=other   map_conflict      same name, other bytes -- it receives the host's content
#   client 3  pretend=absent  map_absent_entry  the game cannot even OPEN the map at lobby entry (mp:X2e)
#   client 4  (no knob)       map_have          already holds the content -- nothing is transferred

# shows the status line naming that peer), so clients 2-4 park on `awaitsignal go` right before their Join click

# until the LAST download finishes, then Start is released once and the match launches for all five peers.
#
# Every check is per client: tools/check_map_transfer.py --client N judges ONE joiner against the host lines that
# name it. Pair with mp_client_map_xfer_{a,b,c,d}.txt.
