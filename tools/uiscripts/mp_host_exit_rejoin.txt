# horizon pinned at the 10000 ms initial advertisement forever (peer0 climbing while peer1 stayed
# == 10000 throughout): the 9999 freeze. This scenario reproduces that exact shape with a real
# process boundary in the middle, which ghost_leave_rejoin's same-process re-join cannot.
