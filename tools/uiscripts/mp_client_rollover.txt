# SES1b (CLIENT): three Join -> occ 2 -> (host leaves) rounds in ONE instance, no match played.
# Pair with mp_host_rollover.txt -- see its header for the shape, the post-check, and the signal
# contract (c<N>_shot / c<N>_ready).
#
# ONLY THE HOST ACTIVELY LEAVES each round (its `clickl Cancel`) -- this peer is always PASSIVELY
# ejected, exactly as mp_client_rejoin.txt's round 1 is: detected by `absent Network players` +
# `sessions <1` (the lobby list emptying), never by a signal from the host saying so. The
# `sessions <1` BEFORE the next round's `sessions 1` is not decoration -- mp_client_rejoin.txt's own
# comment records the U26 bug this order fixes: `sessions 1` alone can match the OLD, about-to-be-
# withdrawn session row, and the `Join game` click that follows lands on a row the browser has
# already refreshed away.
settled value:110
clickv 110
present Player name
settled Ok
clickl Ok
