# (CurrentSystem-1)*3 + 0x17 + VIEW_SIZE_MODE -- three authored backgrounds per system, one per STOCK mode
# -- and the picker stores its list index there, so 1280x768 (index 3) walked into the NEXT system's art
# (an 800x576 image) and llm_ui_widget_list_draw_frame_layer copied WindowWidth*WindowHeight words from it.
# The fix clamps the index to min(mode, 2) and makes the copy header-aware: art that is not the window's
# size is SCALED to fill the window with the [video] filter.
#
# RES6: this row runs with [video] galaxy_native=0 (video_picker_galaxy.ini). By default the galaxy screen now switches to
# the stock 1024x768 mode and never reaches the scaled-background guard below; the galaxy_native_* rows cover that
# path, and this one is their fix-off twin and the guard's coverage.
