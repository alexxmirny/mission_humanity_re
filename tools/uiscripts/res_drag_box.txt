# res_drag_box (RES12) -- the wide arm, the crash row and the parity differential
# The SAME drags (the body below is identical in res_drag_stock.txt and res_drag_box.txt) run in two processes:
#   res_drag_stock: 1024x768, view 864 px < half the 2048 px map, the wrap splice OFF ([video] wrap_window=0): the game's own
#                   corner conversion -- the vanilla reference. Its result is committed as tools/data/drag_box_vanilla.json.
#   res_drag_box:   this script's in-game size change to 1920x1056 (K = 288), the splice and the drag-box fix ON.
# Both start from 2-almost.sav with the camera at world 1440,1696, so the same screen coordinates are the same world
# coordinates (every coordinate stays inside the 864 x 736 stock view). Each drag logs `; [sel] <label> ...` (the selection)
# and the draw logs `; [drag_box] ...` (the world box and the outline it was drawn at) to mh_video.log; the order the last
# selection is given lands in mh_rec_orders.bin. tools/check_drag_box.py compares them with the oracle.
# A drag is HELD: `presshold` makes the cursor moves carry the left button, as a hand-held mouse's do (a plain `press`
# followed by `cursorhold` releases the button on the first move). The camera scrolls with a held arrow key (0x4d right, 0x4b
# left, 0x48 up, 0x50 down), ~11 px per frame.
