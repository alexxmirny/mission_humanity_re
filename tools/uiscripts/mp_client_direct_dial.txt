# mp:R7a DIRECT-DIAL CLIENT walk: with `[net] relay` set in the CLIENT ini, use *Internet server* +
# a typed address and connect DIRECT -- the relay is configured but MUST NOT be contacted for this dial.
#
# WHAT THIS PROVES, and how it differs from relay_browse. relay_browse (R2) reaches the same session
# browser and its Connect goes THROUGH the relay, because the game it wants is a relay-directory row.
# Here the host is NOT on the relay (relay_client_only in test_ui.py), so there is no directory row --
# and since R7a the session browser's *Internet server* + typed IP is a genuine direct dial: the
# client dials the host's LAN address itself. Since mp:R7b the first browser still probes the relay
# (a directory-only leg), and the Connect releases that leg before dialling direct. The post_check
# (check_direct_dial.py) reads the client's mh_net.log for no relay contact AFTER the DIRECT decision
# and the relay's log for forwarded=0; the script's own `occ 2` is what proves the pair still reached
# the lobby DIRECTLY.
#
# HOST: mp_host_lobby.txt (a plain UDP host, off the relay), test_ui.py direct_dial_with_relay_set.

# 1. main menu (NETWORK GAME = value 110)
settled value:110
clickv 110

# 2. player-name screen (accept the default name)
present Player name
settled Ok
clickl Ok

# 3. local-games browser -> *Internet server* (the direct-IP path). This is the screen R7a keeps as a
# genuine direct dial even with a relay configured.
present Internet server
settled Internet server
clickl Internet server

# 4. IP-join window: Server address pre-filled from the pinned list -> Connect (a DIRECT dial to it)
present Server address
settled Connect
clickl Connect

# 5. the host is listed (over the direct connection's own advert) -> Join it
sessions 1
settled Join game
clickl Join game

# 6. the joined lobby, seated on both peers -- occ 2 proves the DIRECT dial reached the lobby
present Network players
occ 2
settled Cancel
capture d_direct_lobby
log CLIENT connected DIRECT with a relay configured -- the relay was never contacted
end
