# mp_client_start.txt's walk (join by IP -> lobby -> enter on the host's Start), then the part that
# is this scenario's own: open the hidden console the way the field player did -- Shift+Enter, which
# opens the SAME text line the chat uses but with _G_LLM_CHAT_MODE = 3 (llm_strat_input_update
# 0x00441c82: the Shift arm is not gated on the session mode; plain Enter is the chat and is) --
# type `_NUCLEAR BOMB` (cheat catalog idx 0x25, "credit conquest kills"), assert the buffer, and press Enter,
# which hands the line to llm_debug_console_dispatch. Then run the match on to 12 s so whatever the
# line did has had ~6 s of lockstep to show, and quit through ESC -> Quit -> Yes the way
# mp_client_gquit.txt does, because the field crash came ON THE QUIT PATH after the cheat.
#
# THE ASSERTION IS THE post_check, NOT THE PIXELS (tools/check_cheat_gate.py): this peer's
# mh_net.log must carry `; [chat] submit mode=3 ... cheat_idx=0x25` AND `; CH1: cheat '_NUCLEAR
# BOMB' (idx 0x25) refused in a network game`, no `*** DESYNC` sample on either peer, and no peer
# eliminated (`presence_lost ... gate=eliminated`) -- with the gate OFF ([input] cheat_gate=0,
# ini/cheat_gate_off.ini) the order goes out on the lockstep stream and the host's base dies.
#
# Runner: ui_test.py --host mp_host_cheat.txt --client <ip>:mp_client_cheat.txt
